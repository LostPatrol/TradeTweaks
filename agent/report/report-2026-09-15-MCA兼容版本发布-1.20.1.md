## 环境说明

- 本机 IDEA 与命令行均在 Gradle 读取项目配置前遇到 Java NIO 回环连接异常 `Invalid argument: connect`。
- IDEA 自身 HTTP 客户端也记录了相同异常，说明该问题不是 Trade Tweaks 构建脚本或依赖导致。
- 为避免修改或重建用户的 IDEA/JDK 环境，本次正式产物由仓库既有 GitHub Actions 构建，并新增了七天保留的生产 JAR 构建产物。
- CI 产物名称使用不可变的 Actions run ID，避免 Pull Request 引用名称中的路径分隔符导致上传失败。
