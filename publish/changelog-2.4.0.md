# 2.4.0 CHANGELOG

## Minecraft 1.20.1

### ADD

+ Added Fabric support, including all six Emerald Wand modes and its quick selection wheel, searchable trade replacement and librarian enchantment selection, villager conversion and restocking tools, Hero of the Village raid rewards, advancements, and interactive trade broadcasts. Fabric API is required on both client and server; the configuration library is bundled.

### CHANGE

+ Downloads now include explicit loader labels. Forge remains supported.
+ Third-party mod compatibility depends on the Minecraft version and loader; Forge/NeoForge compatibility does not automatically apply to Fabric.

### FIX

+ Fixed crafting an Emerald Wand with a Nether Star failing to produce an upgraded wand on Fabric for Minecraft 1.20.1.
