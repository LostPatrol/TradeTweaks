# 2.0.0-CHANGELOG

# ADD

+ Added a wand mode wheel GUI for faster Emerald Wand mode switching.
+ Added the Book of Enlightenment, which can turn a nitwit villager into an unemployed villager.
+ Added the Restoration Bottle, which instantly cures a zombie villager.
+ Added the Reversion Bottle, which turns a villager into a zombie villager while preserving its data.
+ Added the Totem of Village Hero. Using it increases the Hero of the Village level by 1, up to level 5, and adds 5 minutes to the effect duration.
+ Winning a raid now rewards Totems of Village Hero based on the raid level.
+ Added a server command to enable or disable enchanted book trades in librarian trade selection.
+ Added the Restock Writ, a consumable item that can force an out-of-stock villager to restock. Each additional use on the same villager on the same day costs one more writ.
+ Added sounds and particle effects for villager upgrade, profession reset, enlightenment, reversion, restoration, and Hero of the Village item use.
